# LinkCraft Pro — Gestão de Links Curtos de Marca & QR Code Pro

Plataforma ágil e profissional para encurtamento de URLs com domínio personalizado, geração de QR Codes em alta resolução e telemetria de cliques em tempo real, conectada ao banco de dados PostgreSQL na nuvem via Supabase.

---

## 🚀 Funcionalidades

- **Encurtamento com Slugs Amigáveis:** Crie links curtos memoráveis (ex: `/proposta-2026`, `/portfolio`).
- **Gerador de QR Code Pro:** Escolha a cor da sua identidade visual (Azul Real, Esmeralda, Roxo, Laranja ou Grafite) e faça download em PNG de alta resolução pronto para impressão gráfica ou digital.
- **Contador de Cliques & Analytics:** Registro persistente no PostgreSQL do Supabase de cada acesso.
- **Redirecionamento Inteligente:** Parâmetro `?r=slug` que contabiliza a métrica no banco e direciona instantaneamente para o link original.
- **Componentes Uiverse Integrados:** Cards táteis de links com isolamento estrito de CSS (`.uiv_scoped_card`).
- **Copiar com 1 Clique:** Feedback visual imediato para compartilhar no WhatsApp e redes sociais.
